# Debate AI Docs

This is the documentation site for [debate-ai.com](https://debate-ai.com).

## What's here

| Section | Description |
|---------|-------------|
| **[Guides](/docs/features)** | Task-oriented walkthroughs for the app's three tool groups: [Training](/docs/features/tournaments-judge/training-tools), [Practice](/docs/features/rounds/practice-tools), and [Research Collaboration](/docs/features/research-evidence/research-collaboration). Every tool page in the app links back to its guide. |
| **[Features](/docs/features)** | Behavior specifications for every product feature, sourced from `docs/features/` in the monorepo. |
| **[Packages](https://github.com/debate/debate-ai.com/tree/master/packages#readme)** | Index of every workspace package in `packages/`, hosted on GitHub. |

For a product overview of CARDS, FIAT, LEARN, STREAM, and REASON, see the [root README](https://github.com/debate/debate-ai.com#readme).
