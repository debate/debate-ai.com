# Briefs

1. Overview
This is a compiled list of all brief organizations currently in operation alongside lists to their websites. If an organization is semi-regularly releasing files, please place them in the Other subsection below. Several organizations also produce free and paid versions of their files. Use your best judgement on whether the free versions are sufficient as stand alone files or if they serve mostly as teasers to encourage you to buy the paid versions.
