# Practice Drills

==Shows every drill set the AI Drill Generator has made==, grouped by round —
==overview, frontline, cross-ex, and collapse-scenario prompts derived from
that round's flow==.

Open it from the **Practice Drills** tab of **Practice Debates**, in the
sidebar's **Practice Debates** section. Old links to it still work.

## What it shows

Each drill set is its own card with kind badges
(Overview/Frontline/Cross-Ex/Collapse) and a difficulty rating
(easy/medium/hard, ==derived from the argument's vulnerability score==). Each
drill has a "Get AI script" action, ==a "Mark practiced" toggle with a
progress meter==, and a "Review reminder" date field with a "Due" badge. A
"Practice tier" card ==feeds practiced-drill counts into the Progress
Unlocks tier system==.

## Good to know

The "Practice tier" card ==only counts drills from this page==, not your
activity across the other tools in Progress Unlocks.
