# Task Inbox

==Shows every research task routed to a contributor, grouped by topic==, so a
contributor or coach can see what's assigned, ==mark tasks done, and have a
different contributor verify them before they count as complete==.

Open it from the **Routing** tab of the [Research Workspace](/docs/features/research-evidence/research-collaboration).

## What it shows

Per topic: task, coverage level, assignee, a "Mark done" action (moves to
**Awaiting verification**, ==where a different contributor must==
**Verify**), a "Reassign"/"Assign to…" control, a priority flag, a "My
tasks" filter, and a **Team capacity** view.

## Good to know

- "My tasks" ==takes a typed name== — signing in only fills it in for you.
- ==Anyone can reassign tasks or set priority==; there is no coach-only
  permission yet.
