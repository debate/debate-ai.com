# Group Challenges

==Lets a coach create a squad-scoped friendly challenge== — either "reach N
matching contributions" or "reach N recorded wins" — with a roster and a
challenge window, ==showing every challenge's live standings==.

Find it at **/research/cards/group-challenges**.

## What it shows

Each challenge ==is its own card==: title, goal,
window, roster, and ==live standings (best first, 🏆 marking the MVP)==. A
"reach N wins" challenge gets a "Record a win" action.

## Good to know

"Record a win" ==takes a typed name, not a login== — signing in only fills it in
for you.
