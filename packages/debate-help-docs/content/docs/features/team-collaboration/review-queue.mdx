# Review Queue

==Lets a user move a submitted card through peer review== — start a review,
submit it, leave and resolve comments, request changes, approve, and
publish — ==before it goes live in the Shared Evidence Library==.

Open it from the **Review** tab of the [Research Workspace](/docs/features/research-evidence/research-collaboration).

## What it shows

Every review with its status, lifecycle action buttons, a
comment thread (with severity and a "Resolve" action), ==an
unresolved-blocking warning, a review-aging badge==, and a **Reviewer
workload** table. Approve/reject/publish ==are gated on the acting
reviewer's own Progress Unlocks tier and blocked for self-review==.

## Good to know

==The reviewer is a typed name, not a verified account== — signing in only
fills it in for you.
