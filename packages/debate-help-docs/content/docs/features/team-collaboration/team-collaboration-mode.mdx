# Team Collaboration Mode

==Lets a teammate leave a live prep note against a shared topic sprint==, and
shows every note grouped by topic.

Find it at **/research/cards/collaboration**.

## What it shows

A form to add a note, notes grouped by topic with status-cycle and
assign/unassign actions, ==a live "active now" roster== per topic, and ==the full topic sprint==
(quests, task routing, progress board, notes) plus an **End-of-sprint
retrospective** download.

## Good to know

==Name fields take typed text== — signing in only fills them in for you.
