# Debate AI Docs

This is the documentation site for [debate-ai.com](https://debate-ai.com), covering:

- **[Guides](/docs/features)** — task-oriented walkthroughs of the app's tool groups: [training](/docs/features/training-tools), [practice](/docs/features/practice-tools), and [research collaboration](/docs/features/research-collaboration). Every tool page in the app links back to its guide.
- **[Features](/docs/features)** — behavior specs for every feature in the product, sourced from `docs/features/` in the monorepo.
- **[Packages](https://github.com/debate/debate-ai.com/tree/master/packages#readme)** — the index of every workspace package in `packages/`, on GitHub.

See the [root README](https://github.com/debate/debate-ai.com#readme) for a product overview of CARDS, FIAT, LEARN, STREAM, and REASON.
