# Quick Cards Cloud Save

==Syncs your Debate Editor Quick Cards (your library of reusable snippets) to
your account when you're signed in==, like your flows, rounds, word-count
history, judge decisions, editor documents and Speech Documents send log.
Before this, ==the library lived on one device only==.

## What it does

When the editor opens, ==your library is merged once with your account==: ==a card
saved from another device but missing here is added==, and a card that exists
only here (saved offline, or before this feature) is uploaded — ==neither side
ever overwrites the other, it only fills gaps==. After that, every card you add,
edit, import, delete, or clear ==is saved to your account==. Signed out, ==the
library keeps working exactly as before, on this device only==.

==An edit never overwrites a newer one==: if a card was changed on another device
and that change hasn't reached this browser yet, ==this browser takes the newer
version instead of losing it==.
