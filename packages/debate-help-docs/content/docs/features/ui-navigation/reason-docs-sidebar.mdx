# REASON docs sidebar — your files and Topic Starters, opened in Debate Editor

The two collapsible sections, **Topic Starters** and **My Personal Documents**,
==that make up the sidebar in Debate Editor and the card search==. ==Click a file in
either one and it opens in Debate Editor in the main column==.

## The sidebar

In Debate Editor and the card search, ==the two sections are all the sidebar
shows==, under the dock; ==the dock is the way back out==, and any other destination
brings the full sidebar back. The phone drawer does the same. An **Evidence
Library** link above them opens the card search. ==Arriving in the card search opens
the sidebar== if it was hidden, so you start with your documents on screen.

==Each section has a chevron header and starts expanded==, and ==collapsing one is
remembered on this device==. ==With both open, drag the bar between them up or down
to give one more room== — with a mouse, a finger, or the arrow keys — and ==the split
is remembered too==.

## Tabs above the editor

==Every file you open gets a tab in the strip above Debate Editor== — your own
documents and public Topic Starters alike. Opening a file ==adds a tab beside the
ones already open instead of replacing it==; ==opening one that's already open
switches to its tab==. Click a tab to switch to it, or its × to close it.

==Each tab keeps its own undo history while the page is open==: ==Undo in one tab
only undoes edits made in that tab==. ==Reloading the page starts every tab's history
fresh==.

Right-click a tab for **Close**, **Close others**, **Close to the right**,
**Close all**, and **Undo close** (==reopens the last closed tab, up to 20 back==).
==Closing the tab you're on moves to its neighbour==.

### Suspended tabs

==Only five tabs are kept live at once==, to keep the page light. Open a sixth and
==the tab you used least recently is suspended==: it ==stays in the strip==, dimmed with
a moon icon, but ==it's unloaded from memory==. The moon menu at the end of the
strip lists every suspended tab and ==can close them all at once==. ==Clicking a
suspended tab reloads it with all your edits==; only ==its undo history starts
fresh==. ==The tab on screen is never suspended==.

## Links to a file

==Every open file has its own address, named after its title==, so you can bookmark
it or share the link. Two files with the same title get a short code added to tell
them apart. ==The address follows a file that's renamed while open==, and older
links keep working. ==A link to a file that's been renamed, deleted or isn't yours
opens your first file instead of an error==.

### Your own file addresses

==Your own files live under your username==, then the folder they're in, then
the file's name, such as **/alexgul/aff/k-aff-answers**. ==Your username comes
from your account name==, letters and digits only. If someone already has it,
yours gets a number on the end (**alexgul2**). Older **/reason-editor?doc=** links
still open the file and then switch to the new address. While you're signed
out, your files keep the older address.

### Topic Starter addresses

A public Topic Starter's link ==names the resolution it's for and where the file
sits in the library==, such as **/docs/vcx27/neg/cp/aca-expansion-cp-cndi-2026**.
==The topic code is the format and the last two digits of the year==, plus, for the
formats that change topic during the season, ==a letter for which topic of that
year==:

| Format | Code | Example |
| --- | --- | --- |
| High-school policy | vcx + year | `vcx27` (National Health Insurance) |
| High-school policy before 2000 | vcx19 + year | `vcx1928` (1927-28, Department of Education) |
| College policy (NDT/CEDA) | ndt + year | `ndt27` |
| Lincoln-Douglas | ld + letter + year | `lda27` (September), `ldb27` (November) |
| Lincoln-Douglas before 2000 | ld + letter + 19 + year | `lda1999` (1998-99, September) |
| Public Forum | pf + letter + year | `pfa27` |
| Big Questions | bq + year | `bq27` (Tech Ethics) |

Older links that put the letter last (`pf24a`, `ld21b`) ==still open the same
topic==.

Two dropdowns on one line above the Topic Starters tree — a small **format**
picker and the **topic** picker — ==go to a topic's address==. The topic dropdown
==lists the format's topics from the 2015 season (2014-15) on, grouped by year,
newest first==. Older topics, including every national high-school policy
resolution from 1927-28 and every NSDA and NCFL Lincoln-Douglas topic from
1979-80, ==are on the [Topics & Statistics](/practice/statistics) page==: pick
**Older topics…** at the bottom of the dropdown to go there. A link to an older
topic's address still opens it, and that topic stays in the dropdown, under
**Older**, while it is open. ==Every NSDA topic is listed==, from the September/October topic
through the NSDA Nationals topic (filed under June) and the NCFL Nationals
topic (filed under May). A link with just the topic code ==opens that topic's
first starter==.

## Older links

==Older links keep working==: a Topic Starter link from before topic codes were
added still opens the file and then switches to the new address. A link with no
topic code ==opens under the newest high-school policy topic==.

## Your files load fast and work offline

==The sidebar keeps a list of every Topic Starter and every one of your own
files on this device==, so ==the tree is on screen right away== when you come
back, before the server answers, and ==it stays there offline==. A fresh copy is
fetched in the background and replaces the stored one. The Topic Starters list
is refreshed every day and whenever the library is edited.

- ==A file's content is downloaded when you open, download or copy it==. A file
  you've already had open on this device opens with no wait.
- ==Only files changed on another device or tab are downloaded again==; files
  deleted elsewhere drop out of the tree.
- ==If the server can't be reached, your local copy stays== instead of the tree
  going empty.
- ==Each browser copy belongs to one account==: signing in as someone else on
  this browser clears the previous account's tree and tabs and loads the new
  account's files.
- ==An edit can never be saved over a file whose content hasn't loaded yet==.

## File details on hover

==Hover over any file to see its details==: when it was last modified, who wrote it,
its year, and how big it is — pages, quotes (evidence cards), blocks and
characters.

- ==Each file also shows its quote and block counts as small badges== beside its
  name: blue for quotes, grey for blocks. A count of zero shows no badge.
- The author is the name saved in the Word file when it has one; otherwise it's
  whoever uploaded it.
- A Topic Starter's year is its topic's season. Your own files show the year you
  made them.
- Pages are an estimate (about 3,000 characters a page).
- Older files can show "not counted yet" until they're counted.

## Argument-type badges on Topic Starters

==Every Topic Starter shows a small coloured badge for what kind of argument it
is==, read from the file's name and its folders (`Neg/DA/Politics`, `Federalism
CP`, `T - Substantial`), nearest first.

| Badge | Means | Color |
| --- | --- | --- |
| `AFF` | Affirmative case (1AC, plan) | blue |
| `ADV` | Advantage | sky blue |
| `A2` | Aff answers (2AC blocks, "AT …") | indigo |
| `NEG` | Case negative (answers to an aff) | rose |
| `T` | Topicality | amber |
| `CP` | Counterplan | green |
| `DA` | Disadvantage | red |
| `K` | Kritik / critique | purple |
| `TH` | Theory, framework | slate |
| `IMP` | Impacts | orange |
| `DOC` | Nothing to go on | grey |

==Aff badges are all shades of blue; each neg position has its own colour==. A file
with no type word takes its side's badge. Hover a badge for its full name.

## Read-only Topic Starters

==A Topic Starter opens read-only==: ==no toolbar and no AI tools==, and its tab names
it. ==To change one, edit your own copy== (see below). ==Topic Starters open in read
mode==.

## Each topic has its own tree

==Picking a different format or topic shows a different Topic Starters tree==. Files
added before topics existed are in the newest high-school policy topic's tree.
==New folders, "Add to Topic Starters" and "Organize by argument" all work inside
the topic on screen==.

## Organising files

==Every file is a Debate Editor file whatever it was uploaded as==, so ==the name is
the whole label==. ==Right-clicking a file opens the same menu as its "…" button==:

- **Topic Starters:** Open, Edit a copy, Save to my files, Copy link, Download as
  .docx, and — when you're signed in — Rename, Move to and Delete (folders also get
  New folder).
- **Share…** ==opens the file in the editor with the share-with-contacts dialog
  already up==, since ==sharing starts a live co-editing session==.

The **Sort** button in the My Personal Documents header ==orders the tree by name
(A–Z or Z–A) or by last modified==. ==Folders always come first==, and ==the choice is
remembered on this device==.

## Moving files between Files and Topic Starters

==Files drag both ways between the two trees==:

- **Topic Starters → Files:** ==saves your own copy into the folder you drop on==. ==A
  folder comes with everything in it==. "Save to my files" does the same.
- **Files → Topic Starters:** ==submits the file to the public library==. Anyone
  signed in can; ==a moderator's or admin's file goes in at once, and anyone else's
  waits for a moderator's approval==.
- **Topic Starters → Topic Starters:** ==moves it into the folder you drop on==
  (signed in only, approved the same way).
- **Files → Files:** moves it. ==A folder can't be dropped into itself==.
- **Your computer → either tree:** ==uploads it==.

## Editing Topic Starters

==Signed-in readers can rearrange the public library from the sidebar==: rename,
move, delete, add folders and submit their own files. ==Moderators' and admins'
edits apply at once==; ==everyone else's are sent for approval== ("Sent to the
moderators for approval"), and ==nothing changes until a moderator approves it==.
==Moderators get a notification for each proposal== and review them in the admin
panel's **Topic starters** section, where they can also rename, move, copy, paste,
delete and add folders in the library directly. A change that no longer fits (its
file was deleted meanwhile) ==stays in the queue with the reason, to be rejected==.

Admins add Topic Starters with **Sync Topic Starters from openCaselist** in the same
section: ==pick a season and caselist, a format and topic, and press Sync==. ==Each
Word file is converted to a Debate Editor file and filed under that topic==, and
==the card shows progress and any files that failed==, so the page can be closed once
the download is stored.

### Organize by argument (AI)

The sparkle button in the Topic Starters header ==asks the AI to sort every public
file by side and argument type==: affirmative cases under **Aff/Case**, and the
negative's positions under **Neg/DA**, **Neg/CP**, **Neg/T** and **Neg/K**
(==answers to an argument keep its type and take the side that reads them==, so "AT
Elections DA" in an aff file lands in **Aff/DA**; anything else goes under
**Theory** or **Other**). ==The AI reads only file and folder names, never the
files==. ==It shows its plan before anything moves==; ==confirming applies it for
moderators and sends it for approval for everyone else==. ==Existing Aff/Neg folders
are reused, files already in the right place are left alone==, and ==folders left
empty are removed==.

## File manager

The File manager button in the My Personal Documents header ==opens a full-window
file manager over the same files==:

- **Open** (double-click or Enter) ==opens the file in the editor==.
- **Add file, add folder and upload** ==create files in your folders==.
- **Rename, delete, cut/paste and drag** ==rename, delete and move your files==, and
  **copy/paste** ==duplicates them==.
- **Download** ==saves a `.docx`==, the same as the sidebar menu.

==Topic Starters appear in a read-only "Topic Starters" folder==. ==Copying or moving
out of it saves your own copy==; copying or moving one of your files into it
==submits it==. ==Renaming or deleting inside it is refused==.

## Searching files from Ctrl/Cmd-K

The search palette (Ctrl/Cmd-K) ==lists matching files under **Files**==, below the
tools: your own files and the public Topic Starters, matched by name, folder,
**outline headings and contents**. ==Every word you type has to appear somewhere==.
==Name matches come first, then outline matches== (shown as `§ Heading`), ==then
contents matches, which show the text around the match==. ==Picking a file opens it
in the editor==.

Below the files, **Videos & Lectures** ==lists up to eight matches from the video
library==, ==most-viewed first==, once you pause typing. Picking one ==opens its watch
page==. ==The first search through card files can take a moment longer==. In Debate
Editor, ==Ctrl/Cmd-K opens this palette== and Ctrl/Cmd-P ==stays the editor's own==.

## Save status above the editor

The status line over Debate Editor ==says where the open document stands==:
**Unsaved changes**, **Saving…**, or **Couldn't save — retrying** (in red; ==your
edits stay in the tab and it keeps retrying==). ==Once the document is saved the line
disappears==. A Topic Starter shows no line: it's read-only.

## Good to know

- After **Close all** there's no tab left to right-click, so ==reopen a file from
  the sidebar instead of Undo close==. Browsers keep Ctrl/Cmd-Shift-T for
  themselves, so there's no shortcut for it.
- ==Very large uploads to the library can fail==; split a large ZIP into smaller ones.
- ==A file submitted to Topic Starters is limited to about 1.5 MB==.
- The AI organizer ==reads at most 600 files per run, and only their names==, so a
  file named "Untitled" ==lands in **Other**==.
- The File manager ==treats Topic Starters as read-only==; ==rearrange them from the
  sidebar==.
- Choosing an outline match in Ctrl/Cmd-K ==opens the file at the top, not at the
  heading==, and the video results stop at eight.
