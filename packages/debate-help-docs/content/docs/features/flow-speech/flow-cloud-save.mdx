# Flow Cloud Save

==Lets a signed-in user save an individual flow to their account and load it
back on any device==.

Open the flow history dialog: the **Saved to account** tab lists your saved
flows, and each flow chip in the **Rounds** tab has a cloud-upload icon.

## What it does

==Clicking a flow's cloud icon saves that flow to your account==. The **Saved
to account** tab ==lists every saved flow with Load and Remove actions==. ==A
signed-out user sees a sign-in prompt== instead; ==working locally is never
blocked==.

==Saves never silently overwrite a newer copy==. If someone else saved a newer
version of the flow since this browser last saw it, ==the save is stopped
instead of overwriting it==, and the flow's cloud icon turns into a warning
that ==a second click (an explicit "save anyway") resolves==.
