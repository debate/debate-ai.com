# Shared, AI-Generated Debate Flow — Flow Edit Log + Sync

==Lets a contributor log a proposed edit to a specific flow argument== and
==previews how every logged edit merges into the round's flow==, ==flagging
edits that genuinely clash for a person to resolve==.

Find it in the Flow section of the [Coaching](/docs/features/ai-coaching/coaching) page.

## What it shows

A **Flow Edit Log** form, grouped by flow, with a merge preview
(**Shared Flow Sync**) ==showing how many boxes would update and flagging
conflicts==. A **Live sync** toggle ==shares edits across contributors'
browsers as they work==, plus a =="who's editing now" indicator==. ==Conflicts
show as a word-by-word side-by-side comparison==.

## Good to know

- ==Live sync is opt-in, per flow, and off by default==, and ==it checks for new
  edits every few seconds rather than instantly==.
- Your logged edits sync to your account like any other tool's saved work, so
  ==signing in on another device carries your flow edit log with you==. That is
  separate from the Live sync toggle, which is about ==sharing *in-progress*
  edits with teammates in real time==.
