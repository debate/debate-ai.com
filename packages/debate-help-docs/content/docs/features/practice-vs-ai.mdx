# Practice vs AI

Lets a debater run a full timed round against an AI opponent: pick one of
13 opponent personas across five difficulty tiers, set the topic, stance,
and per-phase clocks, debate through opening statements, cross-examination
and closing statements, then get an AI-judged scorecard.

- **Route:** `/versus-ai`
- **Package:** `debate-practice-vs-ai`
- **API:** `POST /api/vsbot/create`, `/debate`, `/judge`, `/concede`

## What it shows

A bot picker across five difficulty tiers (Easy through Legends), a setup
panel (topic, stance, per-phase clocks), the live round (two side-by-side
panels with countdowns, typed or dictated turns), and a scorecard (each
phase scored out of 10 for both sides, totals, a verdict, and follow-up
drill recommendations).

## How it works

A port of the Go `arguehub` vs-bot server and its Vite/React client (kept
as reference sources in the package). The 13 personas carry over field for
field from the Go `GetBotPersonality` switch. Text generation uses
`ANTHROPIC_API_KEY`, falling back to `GEMINI_API_KEY`; with neither set,
each persona answers with an in-character "my systems are offline" line.

## Known gaps

Gamification's score and badges are persisted (`user_settings.practiceVsAiScore`/
`practiceVsAiBadges`) and shown on the scorecard, but there is no real streak
yet: `getGamificationProfile` always reports `currentStreak: 0`, since a real
day-over-day streak needs a dated activity log this table doesn't have — so
the `Streak5` badge is currently unreachable. ~~A reload during a round
returns to the picker.~~ **Fixed:** reloading mid-round now resumes the same
round instead of dropping back to the picker. Only the vs-bot slice of the
Go server is ported.
