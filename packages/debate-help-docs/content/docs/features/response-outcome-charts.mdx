# AI Response-Outcome Charts

Shows every persisted vulnerability report, one card per round — a
per-side exposure summary plus a "most exposed arguments" bar chart.

- **Route:** `/outcomes`
- **Package:** `debate-round`

## What it shows

A per-side exposure summary, a "most exposed arguments" bar chart with a
per-argument "what if" (Extend/Answer/Concede) picker, an "AI Counsel
Panel" action calling a real three-role AI panel (Policy/Kritik/Weighing
Counsel) with an append-only assessment history, and a "Download report"
plain-text export.

## Data flow

```
flow/response-outcome.ts
  → scoreArgumentVulnerability(row) / getArgumentVulnerabilityReport(flow)
state/vulnerabilityReports.ts (localStorage: vulnerabilityReports)
  → panels/VulnerabilityChartsPanel.tsx
  → apps/debate-ai.com/app/outcomes/page.tsx

"Get AI counsel panel":
  → flow/response-outcome-ai.ts + flow/response-outcome-client.ts → POST /api/reason-ai
```
