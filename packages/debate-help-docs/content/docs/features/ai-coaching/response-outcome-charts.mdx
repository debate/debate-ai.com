# AI Response-Outcome Charts

==Shows a vulnerability report for each round you have saved, one card per round== — a
==per-side exposure summary plus a "most exposed arguments" bar chart==.

Find it at **/coaching/outcomes**.

## What it shows

- A per-side exposure summary.
- A "most exposed arguments" bar chart with a ==per-argument "what if" picker==
  (Extend, Answer or Concede) to see how each choice changes your exposure.
- An **AI Counsel Panel** action that ==asks a three-member AI panel== (Policy,
  Critique and Weighing counsel) for an assessment, keeping every past
  assessment in a history.
- **Download report**, a plain-text export.
