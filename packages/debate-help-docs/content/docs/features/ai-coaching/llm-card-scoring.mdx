# LLM Card Scoring

==Scores a debate-evidence card across five dimensions== — relevance, clarity,
uniqueness, evidence quality, usability — ==ranks every card, flags likely
duplicates==, and ==can ask an AI for a written assessment==.

Find it at **/research/cards/scoring**.

## What it shows

A topic switcher, a **Score card** form, a **Bulk import** box (paste several
cards separated by a line of `---`), ==a ranked list with per-dimension scores== and a
**Likely duplicate** badge, and a **Get AI assessment** button per card.
==Evidence Library results also carry a "Score card" action== with an inline
score badge.

## Good to know

- ==Bulk import takes pasted text, not a file upload==.
- ==Scores and AI assessments sync to your account==, but ==they are not shared
  with your team== — a squad member scoring the same card sees their own
  assessment, not a teammate's.
