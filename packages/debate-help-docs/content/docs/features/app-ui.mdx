## Legacy Verbatim / Debate Editor Compatibility [#legacy-verbatim-shortcuts]

Debate Editor ==has the same keyboard shortcuts as Verbatim==. **Mod** means
Ctrl on Windows and Linux and ⌘ on a Mac.

| Shortcut | Command |
| --- | --- |
| `F10` | Apply Emphasis |
| `F8` | Apply Cite |
| `F9` / `Mod-u` | Toggle Underline |
| `F3` family | Condense variants |
| `Mod-Alt-ArrowUp/Down` | Move card/section |
| `Alt-F8` | Copy previous cite |
| `Mod-Shift-k` | Insert short cite tag |
| `Mod-Shift-x` | AI-format a citation |

==Every shortcut can be remapped== in Debate Editor's keybindings editor.

## Offline Storage [#offline-storage]

==Signed in, your account holds the real copy of your work==, and the browser
keeps an offline copy so you can flow without a connection. ==Install the
browser extension for unlimited offline storage== that survives the browser
clearing site data. See **Settings → Storage on this device** for what's
active.

## Quick Cards Cloud Save [#quick-cards-cloud-save]

Signed in, ==your Debate Editor Quick Cards library syncs to your account==.
Cards from other devices are merged in without either side overwriting the
other. Signed out, it stays on this device.

## App nav dock and tool sidebar [#app-nav-dock]

==The icon dock and the sidebar on nearly every page==.

- **Dock:** Videos, Shared, Debate, Practice vs AI and Research (**Alt+1** to
  **Alt+5**), plus a gear menu with search, every sidebar section, settings,
  themes and site links. **Hide Dock** folds it into a small tab.
- **Sidebar:** Videos, Research, Practice Debates, Insights and Docs sections,
  ==one open at a time==, with the page you're on highlighted. Your account
  menu, notifications and **Switch account** (up to five accounts) are at the
  bottom.
- **Resize** by dragging its right edge; **hide** with the panel button or
  **Ctrl+B** (**⌘B**). While hidden, move the pointer to the left edge to peek
  at it.
- **Backspace** goes back to the previous page, unless you're typing in a
  box, an editor or the flow.
- **On a phone**, the dock is a bottom bar and the sidebar opens as a drawer.
- ==Switching pages keeps the video player playing==.

## Features Page [#features-page]

==One page listing every feature in the app==, with a description, link and
docs page for each, in eight category tabs with a search box. It also has the
Chrome extension download, the latest videos and popular cards. Find it at
**/practice/features**.

## REASON docs sidebar [#reason-docs-sidebar]

==The Topic Starters and My Personal Documents trees beside Debate Editor and
the card search==. Click a file to open it in Debate Editor.

- **Tabs:** every file opens in its own tab with its own undo. Only five stay
  live; older ones are suspended (dimmed) and reload when clicked.
  Right-click a tab for Close others, Undo close and more.
- **Links:** each file has its own address, such as
  **/alexgul/aff/k-aff-answers** for your files or
  **/docs/vcx27/neg/cp/aca-expansion-cp-cndi-2026** for a Topic Starter.
- **Topics:** pick a format and topic above the tree; ==each topic has its own
  Topic Starters tree==. Topic codes are the format plus the season's last two
  digits (`vcx27`, `ndt27`, `lda27`, `pfa27`). Older topics are on
  [Topics & Statistics](/practice/statistics).
- **Badges:** each Topic Starter shows its argument type (AFF, ADV, A2, NEG,
  T, CP, DA, K, TH, IMP) and hover shows its size and author.
- **Topic Starters are read-only**; edit your own copy instead.
- **Drag between trees:** Topic Starters → your files saves a copy; your file →
  Topic Starters submits it to the public library (moderators approve
  others' changes).
- **Organize by argument (AI)** sorts the library by side and argument type
  from file names, and shows its plan before anything moves.
- **File manager** opens a full-window view of your files.
- **Ctrl/Cmd-K** searches your files and Topic Starters by name, headings and
  contents, plus the video library.
- ==Your trees load instantly and work offline==; file contents download when
  you open them.

## Expandable Heading Structure [#reason-editor-outline-nav]

==A heading outline beside every Debate Editor document, plus a breadcrumb of
the current heading== (e.g. "Case › Advantage 1 › Uniqueness").

- The **1 2 3 4** buttons ==work like Word's "Show Heading N"== (pockets, hats,
  blocks, tags).
- Drag rows to reorder, and collapse any row.
- Tag rows show the card's cite underneath; the copy button copies all tags,
  or tags with cites and highlighted text.

## Sign in with QwkSearch [#sign-in-with-qwksearch]

==Links your account to [QwkSearch](https://qwksearch.com) so the research chat
runs as you==, with your chats, history and plan's models. In the research
workspace's **Settings → Account**, press **Sign in with QwkSearch**, sign in
on qwksearch.com and press **Allow**. The link covers both the site and the
browser extension. **Sign out of QwkSearch** unlinks it.

## User Settings [#user-settings]

==Settings follow your account across devices when you're signed in==. The
sidebar has:

- **General**: plan, debate style, font, theme, coaching styles, flow
  auto-save, **My team** and **My school**.
- **Debate Account**: passkeys, two-factor authentication, your own AI key,
  and MCP API keys.
- **Sound & speech**: sound effects, read-aloud voice and on-device speech
  models.
- **Privacy**: recording release and deletion requests.
- **Editor** and **Research agent** sections: the same options as the editor's
  gear menu.

### Your own AI key [#user-settings-your-own-ai-key]

Paste an [OpenRouter key](https://openrouter.ai/settings/keys) (`sk-or-…`) or an
Anthropic key (`sk-ant-…`) in **Debate Account → Your own AI key**, and ==AI
features run on your key with no daily limits from Debate AI==. ==The key stays
in this browser only== and is never stored on the server.

### Passkeys [#user-settings-passkeys]

**Debate Account → Passkeys** ==lets you sign in with your fingerprint, face,
screen lock or security key==. Name it and press **Add passkey**. A passkey
only works on the site you made it on.

### Two-factor authentication [#user-settings-two-factor-authentication]

**Debate Account → Two-factor authentication** ==adds a code from an
authenticator app after you sign in==:

1. Press **Set up an authenticator app** and scan the QR code.
2. Enter the code and press **Verify and turn on**.
3. ==Save your backup codes==; each signs you in once if you lose your phone.

Passkey sign-ins skip the code.

### Flow auto-save [#user-settings-auto-save-for-flows-already-on-your-account]

==Flows already saved to your account auto-save a few seconds after you stop
typing==. Change it under **Flow auto-save** in General: **Flows already on my
account** (default), **All flows** or **Off**. A cloud icon on each flow tab
shows whether it matches the account copy (amber means edited since).

==One damaged item never hides the rest==: if a saved flow, round, drill set or
other account item can't be read, everything else still loads, and opening a
damaged flow or round says so, so you can remove it.

### Privacy [#user-settings-privacy]

- **Recording release:** ==nothing you record is published unless you pick I
  agree==. Choose audio and video or audio only.
- **Credit:** anonymous (default), a username, or your real name.
- **Request deletion of your data**, all or part. Admins handle requests and
  you're notified when done.

See the [Terms of Service and Privacy Policy](/legal/privacy).

### Saved to your account [#user-settings-saved-to-your-account]

**General → Saved to your account** ==counts everything stored under your
account== (documents, flows, rounds, practice debates, drill sets and more).
Signed out, a tool that saves only to your account shows ==Sign in to save==
in **Where each tool saves** instead of **Saved to account**.
**Manage** lists, searches, exports and deletes items; **Export all as JSON**
downloads everything; **Restore from export…** adds items back without
duplicating. **Account sync** shows any tool that couldn't sync, and **Where
each tool saves** lists where every tool keeps its data. A tool that keeps
both, such as Practice vs AI, the Reason Editor or AI Judge Decision, ==names
the items saved to your account== (practice debates, documents, judge
decisions) before its synced settings.

## MCP server [#mcp-server]

==Debate AI hosts a [Model Context Protocol](https://modelcontextprotocol.io)
server, so an AI assistant== (Claude, ChatGPT, Cursor, VS Code Copilot…) ==can
search cards, browse videos and transcripts, and read or update your saved
work==.

- **Server URL:** `https://debate-ai.com/api/mcp` (Streamable HTTP)
- **API keys:** **Settings → Debate Account → API & MCP server**

### 1. Get your API key [#mcp-server-1-get-your-api-key]

Public tools (search, videos, transcripts) work without a key. For your own
data, create a key in **Settings → Debate Account → API & MCP server** and
copy it (it starts with `dai_`). ==A key acts as you, so treat it like a
password==; **Reset** or **Revoke** it if needed. Clients send it as a header:

```
Authorization: Bearer dai_your_key_here
```

### 2. Connect your AI tool [#mcp-server-2-connect-your-ai-tool]

The settings page shows a ready-to-paste config with your key filled in.

**Claude Code:**

```bash
claude mcp add --transport http debate-ai https://debate-ai.com/api/mcp \
  --header "Authorization: Bearer dai_your_key_here"
```

**Claude Desktop** (Settings → Developer → Edit Config, needs Node.js):

```json
{
  "mcpServers": {
    "debate-ai": {
      "command": "npx",
      "args": [
        "-y", "mcp-remote", "https://debate-ai.com/api/mcp",
        "--header", "Authorization: Bearer dai_your_key_here"
      ]
    }
  }
}
```

**Cursor** (`~/.cursor/mcp.json`) or **VS Code** (`.vscode/mcp.json`, with
`"servers"` instead of `"mcpServers"` and `"type": "http"`):

```json
{
  "mcpServers": {
    "debate-ai": {
      "url": "https://debate-ai.com/api/mcp",
      "headers": { "Authorization": "Bearer dai_your_key_here" }
    }
  }
}
```

**Claude.ai and ChatGPT custom connectors:** add `https://debate-ai.com/api/mcp`
with no authentication. ==They can't send a key, so you get the public tools
only==.

There is one tool per [Debate AI API](/api) operation. Read-only and delete
tools are marked so your client can ask before running them.
