# Opponent Persona Picker

Lets a user pick the AI practice-opponent style for a session — one of
four built-in personas (Policy Heavy, Kritik, Lay, Fast Flow) or a custom
persona — plus an independent difficulty level (Beginner, Intermediate,
Advanced, Elite).

- **Route:** `/practice-opponent`
- **Package:** `debate-speech-writer`

## What it shows

A form to save a session's opponent persona and difficulty; every session
with a saved `OpponentPersonaSelection` is listed, sorted by `sessionId`.

## Data flow

```
state/opponentPersonaSelections.ts (localStorage: opponentPersonaSelections)
  → panels/OpponentPersonaPickerPanel.tsx
  → apps/debate-ai.com/app/practice-opponent/page.tsx

round/opponent-persona-speech-wiring.ts's getOpponentPersonaForRound(roundId)
  and getOpponentDifficultyForRound(roundId) feed the Online Debate Versus AI
  speech-generation call.
```

## Known gaps

The Practice Round Simulator panel has its own separate opponent-persona
selection embedded in its own setup, rather than reading through this
store.
