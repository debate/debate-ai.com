# Round Cloud Save

==Lets a signed-in user save a whole round== (the tournament, debaters and judges
around a set of flows) to their account and ==load it back on any device==.

Open the flow history dialog's **Rounds** tab: each round has a cloud-upload
icon, with **Save all rounds** and **Save flows not in a round** buttons.

## What it does

A `Round` only references its flows indirectly via `flowIds`, so ==saving a
round also saves each flow it references first==. "Save all rounds" and
"Save flows not in a round" ==cover the bulk cases==. The "Saved to account"
tab's Flows section badges a flow "via round" ==when it was only saved as
part of a round's cascade==.
The same tab's search box ==filters saved rounds by name== alongside saved
flows (see [Flow Cloud Save](/docs/features/flow-speech/flow-cloud-save)).

==Saves never silently overwrite a newer copy==, the same as [Flow Cloud
Save](/docs/features/flow-speech/flow-cloud-save): if someone else saved a newer
version of the round since this browser last saw it, ==the save is stopped
instead of overwriting it==, and the round's cloud icon turns into a warning
that ==a second click (an explicit "save anyway") resolves==. ==Each of the
round's flows is checked the same way on its own==.

## Bulk saves skip what hasn't changed

**Save all rounds** and **Save flows not in a round** ==skip any flow or round
that hasn't changed since it was last saved==, and report it as saved straight
away. ==The cloud icon on a single round or flow always saves==, since that's an
explicit choice. ==After you reload the page, the next bulk save saves everything
once==.

## Pinned debates follow your account

The star on a round in the history dialog (and the **Featured** section of the
debate start screen it feeds) ==used to live only in one browser==. ==A signed-in
user's pinned rounds now appear on every device==, ==once that round has been
saved to the account==. ==A pin whose round isn't saved or on the current device is
skipped== rather than shown. Pins from before this change ==start syncing the next
time you pin or unpin a round==. When pins from two devices add up to more than
12, ==the start screen shows the newest 12==.

## Flow editor settings follow your account

==The flow editor's preferences== — font, default zoom, theme, side colors, vim in
the RFD editor, paste/append behavior, scroll zoom, tooltips, Debate Editor
options and your custom keyboard shortcuts — ==sync to your account==. ==Signing
in on another device applies them there, live==. ==Settings that describe a
machine rather than you stay local==: the flows folder, panel layout (sidebar,
RFD drawer) and the live-collab toggles, name and contacts. ==The last device
to sync wins for all synced settings at once==.
