# Round Cloud Save

==Lets a signed-in user save a whole round== (the tournament, debaters and
judges around a set of flows) to their account and ==load it back on any
device==.

Find it in the Flow History dialog's "Rounds" tab: a cloud-upload icon on each
round, plus **Save all rounds** and **Save flows not in a round** buttons.

## What it does

==Saving a round also saves each of its flows==. **Save all rounds** and
**Save flows not in a round** ==cover the bulk cases==. The "Saved to account"
tab's Flows section badges a flow "via round" ==when it was only saved as
part of a round==.
The same tab's search box ==filters saved rounds by name== alongside saved
flows (see [Flow Cloud Save](/docs/features/flow-speech#flow-cloud-save)).

==Saving never quietly overwrites a newer copy==, just like [Flow Cloud
Save](/docs/features/flow-speech#flow-cloud-save): if someone saved a newer
version of the round from somewhere else since this browser last saw it, ==the
save is rejected with a conflict instead of silently overwriting it==, and the
round's cloud icon turns into a warning that ==a second click (an explicit
"save anyway") resolves==. ==Each of the round's flows gets the same check on
its own==.

## Bulk saves skip unchanged items

**Save all rounds** and **Save flows not in a round** ==skip a flow or round
that hasn't changed since it was last saved in this session==, and report it as
"saved" right away. ==The cloud icon on a single item always saves==, since
that's an explicit action. ==After a fresh page load, a bulk save sends
everything once again==.

## Pinned debates follow your account

The star on a round in the history dialog (and the **Featured** section of the
debate start screen it feeds) ==follows your account==, so ==a signed-in user's
featured rounds appear on every device==. ==A pin finds the same round on
another device once that round has been saved to your account==; ==a pin whose
round isn't on the current device yet is skipped== rather than shown. When pins
from two devices add up to more than 12, ==the start screen shows the newest
12==.

## Flow editor settings follow your account

==The flow editor's preferences== — font, default zoom, theme, side colors, Vim
in the RFD editor, paste/append behavior, scroll zoom, tooltips, Debate Editor
options and your custom keyboard shortcuts — ==sync to your account==.
==Signing in on another device applies them there, live==. ==Settings that
describe a machine rather than you stay local==: the flows folder, panel layout
(sidebar, RFD drawer) and the live-collab toggles, name and contacts. ==The last
device to sync wins for all synced settings at once==.
