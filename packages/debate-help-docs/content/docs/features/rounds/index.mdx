## Create New Round — Registered-User Invites & Notifications [#round-invites-and-notifications]

==Links the Create New Round dialog's debater, judge and spectator fields to real
accounts==: ==typing suggests registered users==, and ==saving the round invites
everyone on it== — ==a registered user in the app, anyone else by email==.

Open **Create New Round** in the round workspace. Your invites and other
notifications are listed at **/notifications**.

### What it does

When you save the round, everyone you added (except you) is invited: ==a
registered user gets a notification in the app, everyone else gets an email
invite==. ==New notifications pop up while you have a tab open==.

==Editing an existing round also invites anyone you newly added==. ==People
already on the round aren't invited again==.
