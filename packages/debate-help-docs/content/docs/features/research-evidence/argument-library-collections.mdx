# Common Argument Library — Saved Collections

Find it at **/research/cards/argument-library**.

## What it shows

Under the Argument Library's tag filter bar, a **Saved collections**
==section appears whenever the library has at least one saved collection==:

- ==Every saved collection is a button== (its name plus tag count) —
  clicking it ==replaces the tags you have selected with that
  collection's saved tags==. Beside it are **Rename**, **Update** (shown once at
  least one tag is active — replaces the collection's tags with your current
  selection), and a small **✕** remove button.
- **Rename** swaps the button for a text field; ==renaming onto another saved
  collection's name is refused== (ignoring capitals) rather than merging.
- A **Save current selection as** field and **Save collection** button ==save the
  tags you have selected under a new name==. Disabled until at least one
  tag is selected and a name is typed.

==Collections sync to your account==, and changes made on two devices at
once are both kept rather than one overwriting the other.
