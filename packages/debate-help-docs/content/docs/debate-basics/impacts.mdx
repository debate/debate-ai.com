# 🗂️ Cross-Category Filing Rules

## 📌 Primary Classification
- Systemic impacts: files centered on the functioning or failure of an interconnected system.
- War impacts: files centered on armed conflict, coercion, deterrence, escalation, or organized violence.
- Values impacts: files centered on rights, justice, dignity, legitimacy, or moral evaluation.

## 🔗 Secondary Tags
- Preserve cross-category connections without duplicating the primary entry.
- Taiwan–AI connects war and technology.
- Nuclear winter connects war, climate, and food.
- Algorithmic discrimination connects technology and justice.

## ↔️ Argument Direction
- Retain “Good,” “Bad,” and critique labels in individual file titles.
- These labels identify positions within the library rather than endorsements.

## 🗃️ Versions and Alternate Titles
- Retain numbered versions and alternate titles beneath the same topic.
- Merge files only after a file-level review establishes whether they are duplicates or distinct resources.
