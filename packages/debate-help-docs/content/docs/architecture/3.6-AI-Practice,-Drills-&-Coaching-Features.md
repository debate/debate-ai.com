This leaf page details the implementation, data flow, state management, and component architecture of the AI practice, drills, and coaching feature set within the **FIAT** module (packaged primarily in `packages/debate-round` and companion packages). These features leverage Large Language Models (LLMs) via proxy routes like `/api/reason-ai` to provide sparring partners, automated drill generation, risk-assessed strategy recommendations, pre-round briefings, and squad-wide coaching coordination.

## System Architecture & Feature Mapping

The AI coaching and practice subsystem operates on a local-first state persistence pattern backed by `localStorage` (with optional account synchronization for signed-in users), deriving insights dynamically from active `Flow` states, prompt templates, and historical profiles.

## AI Versus Rounds & Opponent Personas

AI Versus Rounds allow debaters to engage in turn-based sparring against an AI opponent. The system coordinates speech order based on debate format rules and supports customizable AI personas and difficulty levels [docs/features/ai-versus-rounds.md20-23](https://github.com/debate/debate-ai.com/blob/34937310/docs/features/ai-versus-rounds.md?plain=1#L20-L23)[docs/features/practice-opponent.md1-8](https://github.com/debate/debate-ai.com/blob/34937310/docs/features/practice-opponent.md?plain=1#L1-L8) The primary UI for this feature is the `AiVersusRoundPanel`[packages/debate-practice-drills/src/panels/AiVersusRoundPanel.tsx1-10](https://github.com/debate/debate-ai.com/blob/34937310/packages/debate-practice-drills/src/panels/AiVersusRoundPanel.tsx#L1-L10)

- **Persistence:** The `AiVersusRoundPanel` manages the active sparring workspace, relying on `state/aiVersusRounds.ts` to persist `AiVersusRoundRecord` objects in `localStorage`[packages/debate-round/src/state/aiVersusRounds.ts38-56](https://github.com/debate/debate-ai.com/blob/34937310/packages/debate-round/src/state/aiVersusRounds.ts#L38-L56)
- **Turn Order Logic:**`getAiVersusRoundStatus` evaluates submitted speeches against `buildAiVersusSpeechOrder` to determine whose turn is active [packages/debate-round/src/state/aiVersusRounds.ts155-167](https://github.com/debate/debate-ai.com/blob/34937310/packages/debate-round/src/state/aiVersusRounds.ts#L155-L167)
- **Opponent Personas:** Users can select built-in personas (`Policy Heavy`, `Kritik`, `Lay`, `Fast Flow`) or author a custom persona via `buildCustomOpponentPersona`[packages/debate-speech-writer/src/opponent/opponent-personas.ts1-38](https://github.com/debate/debate-ai.com/blob/34937310/packages/debate-speech-writer/src/opponent/opponent-personas.ts#L1-L38)[docs/features/practice-opponent.md17-37](https://github.com/debate/debate-ai.com/blob/34937310/docs/features/practice-opponent.md?plain=1#L17-L37)

- **Speech Generation & Regeneration:** AI responses are requested via `requestAiVersusSpeech` or `requestAiVersusSpeechWithPersona`, proxying through `/api/reason-ai`[packages/debate-practice-drills/src/panels/AiVersusRoundPanel.tsx20-28](https://github.com/debate/debate-ai.com/blob/34937310/packages/debate-practice-drills/src/panels/AiVersusRoundPanel.tsx#L20-L28) Individual speeches in the history can be replaced using `replaceAiSpeechAt`[packages/debate-round/src/state/aiVersusRounds.ts116-134](https://github.com/debate/debate-ai.com/blob/34937310/packages/debate-round/src/state/aiVersusRounds.ts#L116-L134)

## Practice Round Simulator & Feedback Pipeline

The Practice Round Simulator (`/practice-round`) integrates round configuration, simulated speech exchange, post-round feedback generation, and AI judge decision-making into a unified workflow [docs/features/practice-round-simulator.md1-38](https://github.com/debate/debate-ai.com/blob/34937310/docs/features/practice-round-simulator.md?plain=1#L1-L38) The UI is rendered by `PracticeRoundSimulatorPanel`[packages/debate-practice-drills/src/panels/PracticeRoundSimulatorPanel.tsx1-10](https://github.com/debate/debate-ai.com/blob/34937310/packages/debate-practice-drills/src/panels/PracticeRoundSimulatorPanel.tsx#L1-L10)

- **Setup & Storage:**`PracticeRoundSimulatorPanel` writes `PracticeRoundSetup` configurations to `state/practiceRounds.ts` keyed by `roundId`[packages/debate-round/src/state/practiceRounds.ts38-56](https://github.com/debate/debate-ai.com/blob/34937310/packages/debate-round/src/state/practiceRounds.ts#L38-L56) The `buildPracticeRoundSetup` function composes the round's configuration, including judge paradigm and opponent persona [packages/debate-round/src/round/practice-round-simulator.ts145-152](https://github.com/debate/debate-ai.com/blob/34937310/packages/debate-round/src/round/practice-round-simulator.ts#L145-L152)
- **Post-Round Feedback:** Once a round has been flowed in the workspace, `buildAndSavePracticeRoundFeedback` derives coaching insights against the saved `judgeParadigm` (`buildPracticeRoundFeedback`) [packages/debate-round/src/state/practiceRounds.ts113-149](https://github.com/debate/debate-ai.com/blob/34937310/packages/debate-round/src/state/practiceRounds.ts#L113-L149)
- **AI Judge Decisions:**`round/practice-round-judge-decision-wiring.ts` composes saved flow summaries into `JudgeDecisionAiInput` structures, calling `requestJudgeDecision` to render verdicts [docs/features/practice-round-simulator.md59-63](https://github.com/debate/debate-ai.com/blob/34937310/docs/features/practice-round-simulator.md?plain=1#L59-L63)

## AI Drill Generator & Drill Sets

The Drill Generator (`/drills`) analyzes an active debate flow to automatically construct targeted practice exercises [docs/features/drill-sets.md1-11](https://github.com/debate/debate-ai.com/blob/34937310/docs/features/drill-sets.md?plain=1#L1-L11) The `DrillSetsPanel` is responsible for rendering the UI [packages/debate-practice-drills/src/state/drillSets.ts1-10](https://github.com/debate/debate-ai.com/blob/34937310/packages/debate-practice-drills/src/state/drillSets.ts#L1-L10)

- **Drill Kinds:** Generates `overview`, `frontline`, `cross_ex`, and `collapse` prompt records derived from round arguments [docs/features/drill-sets.md16-25](https://github.com/debate/debate-ai.com/blob/34937310/docs/features/drill-sets.md?plain=1#L16-L25) The `buildDrillsFromFlow` function in `flow/drill-generator.ts` is central to this process [packages/debate-round/src/flow/drill-generator.ts1-30](https://github.com/debate/debate-ai.com/blob/34937310/packages/debate-round/src/flow/drill-generator.ts#L1-L30)
- **Difficulty Derivation:**`vulnerabilityScoreToDifficulty` maps argument exposure metrics (`vulnerabilityScore`) to difficulty ratings (`easy`, `medium`, `hard`) [docs/features/drill-sets.md26-38](https://github.com/debate/debate-ai.com/blob/34937310/docs/features/drill-sets.md?plain=1#L26-L38)
- **AI Practice Scripts:**`requestDrillScript` queries `/api/reason-ai` to generate ready-to-read practice response scripts, persisted via `saveDrillAiScript`[docs/features/drill-sets.md40-50](https://github.com/debate/debate-ai.com/blob/34937310/docs/features/drill-sets.md?plain=1#L40-L50)
- **Completion & Scheduling:** Users can toggle drill completion (`toggleDrillCompletion`) and set review dates (`scheduleDrillReview`), triggering in-app due reminders via `isDrillReviewDue`[docs/features/drill-sets.md67-116](https://github.com/debate/debate-ai.com/blob/34937310/docs/features/drill-sets.md?plain=1#L67-L116)
- **Progress Unlocks Integration:**`state/drillProgressUnlocks.ts` feeds aggregate drill completion stats into the contributor unlock pipeline to award tier badges (e.g., "Rising Researcher") [docs/features/drill-sets.md78-94](https://github.com/debate/debate-ai.com/blob/34937310/docs/features/drill-sets.md?plain=1#L78-L94)

## Scout-to-Strategy Pipeline & Case Evaluation
