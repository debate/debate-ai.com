## 2. Layout Shell Components

The workspace divides the screen into specialized layout sub-components communicating through props and shared store bindings.

### FlowPageSidebar (`FlowPageSidebar.tsx`)

The sidebar houses quick-action buttons (Flow History, Edit/New Round, Tools Menu, Split Mode), the live round status group, and the collapsible list of open flow tabs [packages/debate-round/src/layout/FlowPageSidebar.tsx114-142](https://github.com/debate/debate-ai.com/blob/34937310/packages/debate-round/src/layout/FlowPageSidebar.tsx#L114-L142) On mobile viewports, selecting a flow tab automatically triggers `onCloseMobileMenu` to dismiss the navigation drawer [packages/debate-round/src/layout/FlowPageSidebar.tsx148-153](https://github.com/debate/debate-ai.com/blob/34937310/packages/debate-round/src/layout/FlowPageSidebar.tsx#L148-L153)

### FlowMainContent (`FlowMainContent.tsx`)

Acts as the central viewport switcher. It renders either a single-pane or side-by-side split view of speeches using the CardMirror engine (`LexicalEditorWrapper`) [packages/debate-round/src/layout/FlowMainContent.tsx99-162](https://github.com/debate/debate-ai.com/blob/34937310/packages/debate-round/src/layout/FlowMainContent.tsx#L99-L162) In split mode, only the active pane (`activeSplitSide`) hosts the interactive ProseMirror editor instance, while the secondary pane provides a read-only preview until clicked [packages/debate-round/src/layout/FlowMainContent.tsx129-130](https://github.com/debate/debate-ai.com/blob/34937310/packages/debate-round/src/layout/FlowMainContent.tsx#L129-L130)

### SpeechHeaderBar (`SpeechHeaderBar.tsx`)

Rendered above speech content, providing speech navigation chevrons (`canNavigatePrev`, `canNavigateNext`), timer controls (`SpeechTimer`, `SpeechWordCounter`), view mode selectors (`ViewModeSelector`), and speech recording playback [packages/debate-round/src/layout/SpeechHeaderBar.tsx136-159](https://github.com/debate/debate-ai.com/blob/34937310/packages/debate-round/src/layout/SpeechHeaderBar.tsx#L136-L159)

### LiveRoundGroup (`LiveRoundGroup.tsx`)

This component displays the selected round's prep timers and the full timer/controls bar for the currently selected speech in the main content area. It is the app's sole round-timer surface. Other speeches in the round are listed by name only, as the timer tracks only the speech in view [packages/debate-round/src/layout/LiveRoundGroup.tsx1-12](https://github.com/debate/debate-ai.com/blob/34937310/packages/debate-round/src/layout/LiveRoundGroup.tsx#L1-L12) The `selectSidebarRound` utility function determines which round's timers are shown, prioritizing the round associated with the active flow tab, then the live round, or `undefined` if neither is found [packages/debate-round/src/utils/sidebar-round.ts20-24](https://github.com/debate/debate-ai.com/blob/34937310/packages/debate-round/src/utils/sidebar-round.ts#L20-L24)

### SpeechDocPanel (`SpeechDocPanel.tsx`)

A sliding or docked auxiliary panel used to inspect and edit supplementary speech documents tied to the active debate format.

## 4. Round Pairings

The system supports account-synced round pairings, which are local-first and merged with the user's account when signed in. This functionality is managed by the `useRoundPairings` hook [packages/debate-round/src/hooks/useRoundPairings.ts92-142](https://github.com/debate/debate-ai.com/blob/34937310/packages/debate-round/src/hooks/useRoundPairings.ts#L92-L142)

### Data Flow and Synchronization

- **Local-first storage**: Round pairings are initially stored and managed locally using `state/roundPairings.ts`[packages/debate-round/src/hooks/useRoundPairings.ts89-90](https://github.com/debate/debate-ai.com/blob/34937310/packages/debate-round/src/hooks/useRoundPairings.ts#L89-L90)
- **Account Sync**: On mount, `ensureRemoteMerged` attempts to fetch remote pairings via `listSavedRoundPairings`[packages/debate-round/src/hooks/useRoundPairings.ts45-46](https://github.com/debate/debate-ai.com/blob/34937310/packages/debate-round/src/hooks/useRoundPairings.ts#L45-L46) and merges them with local data. Remote pairings without a local counterpart are adopted, and local-only pairings are pushed to the account [packages/debate-round/src/hooks/useRoundPairings.ts56-71](https://github.com/debate/debate-ai.com/blob/34937310/packages/debate-round/src/hooks/useRoundPairings.ts#L56-L71)
- **Conflict Resolution**: The merge process fills gaps but does not resolve edit conflicts for `roundId`s present on both sides [packages/debate-round/src/hooks/useRoundPairings.ts65-66](https://github.com/debate/debate-ai.com/blob/34937310/packages/debate-round/src/hooks/useRoundPairings.ts#L65-L66)
- **Live Updates**: A `storage` event listener ensures that changes made in other browser tabs are reflected in the current tab [packages/debate-round/src/hooks/useRoundPairings.ts112-119](https://github.com/debate/debate-ai.com/blob/34937310/packages/debate-round/src/hooks/useRoundPairings.ts#L112-L119)
- **Persistence**: `saveRoundPairing` and `deleteRoundPairing` functions handle local persistence, with best-effort attempts to sync changes to the account via `saveRoundPairingToAccount` and `deleteSavedRoundPairingFromAccount`[packages/debate-round/src/hooks/useRoundPairings.ts121-140](https://github.com/debate/debate-ai.com/blob/34937310/packages/debate-round/src/hooks/useRoundPairings.ts#L121-L140)

### API Endpoints

- `/api/round-pairings`: Handles listing and saving round pairings [apps/debate-ai.com/app/api/round-pairings/route.ts](https://github.com/debate/debate-ai.com/blob/34937310/apps/debate-ai.com/app/api/round-pairings/route.ts)

## 5. Mobile Adaptation & Responsive Behavior

The workspace adapts to varying screen resolutions through hook-driven layout adjustments:

- **`useMobileDetection`**: Listens to viewport size constraints and sets `isMobile` state in `DebateFlowPage`[packages/debate-round/src/panels/DebateRoundPanel.tsx37-114](https://github.com/debate/debate-ai.com/blob/34937310/packages/debate-round/src/panels/DebateRoundPanel.tsx#L37-L114)
- **Sidebar Collapsing**: On mobile, the sidebar collapses into a slide-over sheet component (`Sheet`, `SheetContent`), automatically dismissing upon tab selection [packages/debate-round/src/layout/FlowPageSidebar.tsx148-153](https://github.com/debate/debate-ai.com/blob/34937310/packages/debate-round/src/layout/FlowPageSidebar.tsx#L148-L153)
