The `debate-timer` package provides core round timing utilities within the Debate AI platform. This includes React components for speech and prep timers, the timer progress ring UI, per-format speech time definitions, a word-limited speech text counter with microphone dictation integration, and microphone transcription hooks using the browser's native speech recognition API. This package serves as a standalone timer library used primarily by the `debate-round` module for live rounds and practice sessions and for handling timing logic and UIs.

---

## Package Layout

The package divides its source code into `src/` grouped by functionality and `test/` for unit tests:

```
debate-timer/
├── src/
│   ├── audio/        # timer sound effects used during countdowns
│   ├── formats/      # speech time definitions per debate format and word-count formats
│   ├── hooks/        # React hooks, including `useSpeechRecorder` and transcription
│   ├── recorder/     # microphone selector, live waveform visualization, playback components
│   ├── timers/       # core React timer components: SpeechTimer, PrepTimer, SpeechWordCounter, TimerProgressRing
│   ├── types/        # TypeScript types related to timers and speeches
│   └── index.ts      # public package exports entrypoint
└── test/             # Vitest suites, mainly for format tables and utilities

```

This modular organization enables separation of UI components, timing logic, formats, audio handling, and hooks for microphone recording and transcription.

## Speech and Prep Timer Components

### SpeechTimer and PrepTimer

These React components provide the standard UI and timer management for timed speeches and prep periods during rounds. They handle ticking down from predefined speech times, integrating audible cues, and triggering UI updates in the live round workspace.

The timers work closely with the speech time definitions loaded from the format tables to know how many milliseconds each speech type should last.

### TimerProgressRing

The `TimerProgressRing` component renders an SVG circular countdown ring that visually represents timer progress from full (0) to complete (1). This component has no internal state and receives a `progress` value externally, allowing reuse in various places (like the debate-timer-progress browser extension or nav buttons).

Implementation details:

- Renders a 200x200 SVG with a circle radius of 90 units.
- Uses stroke dash offsets proportional to the `progress` value to animate the ring.
- Rotated -90 degrees to start at 12 o'clock.
- Supports customizable stroke width and CSS classes.

## Per-Format Speech Times

The `formats/` directory contains modules defining the timing configuration for various debate styles (e.g., Policy, Parliamentary, Public Forum, Lincoln-Douglas). Each style defines the speech order, names, and durations in milliseconds.

Also included is a `word-count-format` that supports asynchronous, word-limited speeches instead of timed speeches, offering pure functions like `countWords` and `getWordCountStatus` for UI validation and feedback.

Speech times from these format modules serve as the source of truth for which speech columns appear in the flow spreadsheet and for timer logic across the app.

## SpeechWordCounter Component

The `SpeechWordCounter` component is designed for use with word-limited speeches, counting words typed against a word limit instead of counting down time.

### Features

- Shows a live word count and limit readout (e.g., "245 / 300 words").
- Supports editing the speech text inside a popover with a textarea.
- Integrates microphone dictation via a "🎤 Record" button that uses browser transcription.
- Displays progress with a colored progress bar and warning colors near limit.
- Accessibility labels for screen readers and tooltips.

### Implementation and Data Flow

### Props

- `speechName`: String, e.g., `"1AR"`.
- `wordLimit`: Number, max words allowed.
- `text`: The current speech text.
- `onTextChange`: Callback to update text.
- `compact`: Boolean for smaller layout.
- `className`: Additional CSS classes.

### Microphone Dictation Integration

Dictation uses the `useMicrophoneTranscription` hook (see below) to enable live speech-to-text transcription appended into the textarea.

If the popover closes while dictation is active, it stops automatically.

## Microphone Transcription Hooks

The package includes a React hook `useMicrophoneTranscription` that wraps the browser's native speech recognition APIs to transcribe spoken words into text for dictation.

### Feature Detection and Interface

- Detects browser support by checking for `SpeechRecognition` or `webkitSpeechRecognition` constructor presence.
- Provides state booleans: `isSupported`, `isListening`.
- Provides `start()` and `stop()` methods to control transcription.
- Provides an `error` string for user-friendly error messages.

### Underlying Utilities (`microphone-transcription.ts`)

This module implements pure helper functions:

- `getSpeechRecognitionConstructor(host)`: Finds the platform speech recognition constructor, preferring standard over prefixed.
- `isMicrophoneTranscriptionSupported(host)`: Returns `true` if speech recognition APIs are available.
- `appendDictatedSegment(existingText, segment)`: Concatenates new dictated text onto existing field, avoiding double whitespace.
- `describeMicrophoneTranscriptionError(code)`: Maps API error events to readable messages, e.g., permission denied, no speech detected.

### Transcription Process Flow

This hook is used inside components like `SpeechWordCounter` to provide smooth dictation experiences during live or asynchronous speeches.

## Word Count Speech Mode Integration in debate-round

The `debate-round` package integrates with `debate-timer`'s word-count facilities to enable asynchronous, word-limited rounds.

- The `resolveSpeechWordLimit` function in `word-count-speech-mode.ts` determines word limits by:

- Checking user-defined presets.
- Looking up `wordCountStyles` by speech name.
- Estimating limits from timed speech lengths using speaking pace estimates.
- Persistence utilities load, update, and save speech texts for word-limited rounds into localStorage-backed stores shared with the `/word-count` submission UI.
- This ensures a seamless experience with word-limited speeches in both live and practice modes.
