The **Ebb Grid** is the central interactive component of the FIAT debate round workspace, embodying the flow spreadsheet paradigm. Built atop the React wrapper around [Handsontable](https://handsontable.com/), it enables a performant, keyboard-centric and local-first experience for live debate flow tracking. This page documents its internal data model, metadata handling, dynamic column layouts based on debate formats (Policy, PF, LD, Parli), undo/redo for rich cell metadata, codec serialization for persistence, contextual UI interactions, zooming mechanics, and Excel XLSX export capabilities.

## Data Model & Core Types

The data model underlying the Ebb grid models debate flow as structured tabular data enriched with debate-specific metadata.

### Top-Level Types

| Type | Description |
| --- | --- |
| `FlowRound` | The entire debate flow session, containing multiple tabs/sheets representing different argument sets. |
| `FlowSheet` | A single sheet/tab within a round, potentially representing different argument categories (e.g., "Flow 1", "Off-case"). Holds the main data arrays plus metadata. |
| `CellMeta` | Metadata for a single grid cell, encoding visual and logical flags (bold, highlight, referenced evidence card, argument grouping, "kicked" state). |

`FlowSheet` includes:

- `data`: A 2D array of strings representing raw cell text.
- `meta`: A mapping from cell coordinates to `CellMeta` records allowing rich formatting and debate annotations separated from text content.

### `CellMeta` Properties

- `bold`: boolean - bold formatting
- `highlight`: color string or boolean - cell background highlight
- `card`: string identifier linking to evidence cards
- `group`: logical grouping ID for related arguments
- `kicked`: boolean indicating conceding or dropping an argument

This design allows metadata changes without disturbing cell content and optimizes collaborative editing and serialization.

## Event-Driven Column Layout

Rather than hardcoding grid columns, column layouts respond dynamically to the debate format defined by `EventDef` objects.

For example:

| Format | Typical Speech Column Sequence |
| --- | --- |
| Policy | 1AC, 1NC, 2AC, 2NC, 1NR, 1AR, 2NR, 2AR |
| Public Forum (PF) | Constructive A, Constructive B, Rebuttal A, Rebuttal B,... |
| Lincoln-Douglas (LD) | Affirmative Constructive, Negative Constructive, 1st Affirmative Rebuttal, Negative Rebuttal, 2nd Affirmative Rebuttal |
| Parliamentary (Parli) | Varied, but also event-defined |

The `columnsForFlowSheet` method uses these definitions to assemble appropriate grid columns dynamically at runtime, supporting clean code reuse and format flexibility.

## HotGrid: React Integration with Handsontable

`HotGrid.tsx` is the React component wrapping the Handsontable spreadsheet. It manages:

- Rendering of a large grid with thousands of rows (e.g., 250 minimum padded rows)
- Column widths fixed per speech column (280px)
- Spacer columns for inert panel areas
- Keyboard navigation with Excel-style smart jumps across filled and empty cells
- Interaction with a rich metadata overlay distinct from cell contents
- Undo/redo integration for both text edits and metadata changes
- Context menu and presence indicators for real-time collaboration
- Zooming by CSS scaling

Key functions include:

- `runBoundCommand()`: Runs keyboard shortcut mappings for commands (bold, kick, group etc.)
- `smartJump()`: Implements Excel-style jump navigation over runs of filled or empty cells
- `reselectMovingBlock()`: Fixes Handsontable selection visuals after nudges or multi-cell moves

The component interacts heavily with the flow state stores (`useFlowStore`), collab replicas, metaUndo stacks, and the remote operation queueing systems.

## Cell Metadata & MetaUndo

Unlike typical spreadsheets combining text and formatting, Ebb maintains a layered metadata model `CellMeta` for rich debate semantics.

### Undo/Redo for Metadata

- `metaUndo` maintains independent undo/redo stacks specific to metadata ops such as bolding, highlighting, kicking arguments, and more.
- This allows users to undo a highlight addition without altering the text content undo history.
- Functions:

- `attachMetaUndo()` integrates the undo stack into editor state
- `resetMetaUndo()`, `restoreMetaUndo()` manage undo/redo lifecycle
- `snapshotClasses()` captures the current state of cell metadata class assignments

This is critical to separate logical debate annotations from text edits in the flow cells.

## Serialization Codec: Packing & Restoring Grid State

The codec module encodes the flow grid data and metadata compactly for persistence in SQLite or file export.

- Text content is stored in a 2D array.
- Metadata classes per cell are encoded as CSS-like class strings (e.g., "bold", "highlight-high").
- Functions convert between class names and `CellMeta` structures, enabling lossless roundtrip.
- The grid is padded with spare rows ahead to allow editing space.
- Codec handles trimming extra empty rows on save.

This format supports both local-first usage and cloud sync with efficient storage.

- **Undo/Redo Access**: Meta-specific undo/redo from context menu

## Zoom Control Mechanism

Zoom is controlled via the `ZOOM_STEP` constant defining increment levels. The grid container applies CSS transforms to scale up/down the entire Handsontable component dynamically.

This lightweight approach avoids costly grid re-renders and preserves keyboard navigation.

Zoom state is stored in the `useFlowStore` for persistence across sessions.

## XLSX Export Pipeline

For sharing debates with judges or offline review, Ebb supports high-fidelity XLSX exports via the `exceljs` library.

### Export Pipeline Steps

1. **Grid Translation**: The flow sheet's 2D data array is mapped to Excel cells.
2. **Styling**: `CellMeta` flags (bold, highlights, kicked) are translated into Excel cell styles (font boldness, fill colors, strikethrough).
3. **Multi-Sheet Workbook**: Export includes

- The main flow sheet(s)
- An "Info" sheet summarizing session metadata (date, tournament, teams)
- An RFD (Reason for Decision) sheet for judge notes and AI-generated ratings.
4. **Data & Metadata Preservation**: Ensures fidelity from live grid to exported file.

### Key Export Functions

- `exportToExcel(round: FlowRound)`: Entry point that processes all sheets and metadata on the round.
- `applyCellFormatting(cell, cellMeta)`: Applies rich formatting styles to ExcelJS cell objects based on metadata.

This pipeline integrates tightly with the overall flow model to enable seamless export of debate flows.
