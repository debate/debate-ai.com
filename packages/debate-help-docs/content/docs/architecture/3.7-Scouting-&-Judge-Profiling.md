These components provide debaters with systematic tracking for opponent team tendencies, individual judge ballots, multi-judge panel comparisons, and AI judge paradigm selections.

## Opponent Team Profiles & Scouting

The `OpponentTeamProfilesPanel` (`packages/debate-round/src/panels/OpponentTeamProfilesPanel.tsx`) manages scouting data for opposing teams, rendering rosters sorted by rounds recorded and supplying round logging, CSV bulk imports, and side-by-side team comparisons [packages/debate-round/src/panels/OpponentTeamProfilesPanel.tsx1-64](https://github.com/debate/debate-ai.com/blob/34937310/packages/debate-round/src/panels/OpponentTeamProfilesPanel.tsx#L1-L64)

### Aggregation and Data Model

- **`OpponentTeamProfile`**: Generated by `buildOpponentTeamProfile` in `packages/debate-data-sync/src/rankings/opponent-team-profile.ts`, tracking overall wins/losses, unique tournaments attended, and side-specific splits [packages/debate-data-sync/src/rankings/opponent-team-profile.ts87-145](https://github.com/debate/debate-ai.com/blob/34937310/packages/debate-data-sync/src/rankings/opponent-team-profile.ts#L87-L145)
- **Side Preference Threshold**: Flags a notable side preference (`hasNotableSidePreference`) when a team has played at least 5 rounds with representation on both Aff and Neg sides and clears a win-rate variance threshold of 15% (`SIDE_PREFERENCE_THRESHOLD = 0.15`) [packages/debate-data-sync/src/rankings/opponent-team-profile.ts33-36](https://github.com/debate/debate-ai.com/blob/34937310/packages/debate-data-sync/src/rankings/opponent-team-profile.ts#L33-L36)
- **Frequency Ranking**: Ranks `argumentTags` and `caseName` entries by frequency, tie-broken alphabetically via `rankFrequencies`[packages/debate-data-sync/src/rankings/opponent-team-profile.ts69-85](https://github.com/debate/debate-ai.com/blob/34937310/packages/debate-data-sync/src/rankings/opponent-team-profile.ts#L69-L85)

### Persistence and Edit History

- **`opponentRoundRecords`**: Raw round logs are persisted through `packages/debate-data-sync/src/state/opponentRoundRecords.ts`[packages/debate-data-sync/src/state/opponentRoundRecords.ts56-62](https://github.com/debate/debate-ai.com/blob/34937310/packages/debate-data-sync/src/state/opponentRoundRecords.ts#L56-L62) Every record write triggers re-aggregation of the corresponding team profile [packages/debate-data-sync/src/state/opponentRoundRecords.ts60-104](https://github.com/debate/debate-ai.com/blob/34937310/packages/debate-data-sync/src/state/opponentRoundRecords.ts#L60-L104)
- **Undo/Redo Stacks**: Maintains an edit history stack (`MAX_EDIT_HISTORY_PER_RECORD = 10`) per round ID, allowing users to step back or redo corrections via `undoLastOpponentRoundRecordEdit` and `redoLastOpponentRoundRecordEdit`[packages/debate-data-sync/src/state/opponentRoundRecords.ts59-150](https://github.com/debate/debate-ai.com/blob/34937310/packages/debate-data-sync/src/state/opponentRoundRecords.ts#L59-L150)

## Judge Profiles & Round Ballots

- **`JudgeProfile`**: Aggregated via `buildJudgeProfile` in `packages/debate-speech-writer/src/judge/judge-profile.ts` from underlying `JudgeRoundRecordEntry` items stored in `judgeRoundRecords`[packages/debate-speech-writer/src/state/judgeRoundRecords.ts43-71](https://github.com/debate/debate-ai.com/blob/34937310/packages/debate-speech-writer/src/state/judgeRoundRecords.ts#L43-L71)

## Fuzzy Search & Correction Handling

To gracefully handle mistyped IDs during round logging, both scouting and judge profiling packages utilize a Levenshtein edit-distance algorithm to suggest corrections.

### Search Implementation Flow

1. **Exact Substring Match**: The UI searches existing records using case-insensitive substring filters.
2. **Fuzzy Fallback**: If no direct match is found, `findNearestJudgeId` or `findNearestOpponentTeamId` computes distance matrices using `editDistance`[packages/debate-data-sync/src/state/opponentRoundRecords.ts167-176](https://github.com/debate/debate-ai.com/blob/34937310/packages/debate-data-sync/src/state/opponentRoundRecords.ts#L167-L176)[packages/debate-speech-writer/src/state/judgeRoundRecords.ts158-176](https://github.com/debate/debate-ai.com/blob/34937310/packages/debate-speech-writer/src/state/judgeRoundRecords.ts#L158-L176)
