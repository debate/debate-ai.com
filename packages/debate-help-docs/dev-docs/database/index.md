# Database

The app runs on one Cloudflare D1 database (`debate-ai-db`, binding `debate_db`); locally the
same schema runs on SQLite through libSQL. Its tables are documented on two pages:

| Page | What it covers |
| --- | --- |
| [App tables](./app-schema.md) | Every table in `apps/debate-web/lib/database/schema.ts`, with columns, types, keys and what each column is for, plus the FTS search index and migration bookkeeping tables |
| [Tabroom tables](./tabroom-schema.md) | The Tabroom tournament tables from `packages/debate-tournaments/migrations`. Generated by `scripts/sync-upstream.mjs`; edit descriptions in place, they are carried over |

How the tables reach a database is in [Database setup](../setup/database.md).

## Keeping it current

These pages are not regenerated from `schema.ts`. When you add or change a table in `schema.ts`
or a package migration, update its entry here in the same change.
