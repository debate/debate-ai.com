User page: [Debate Editor remembers your zoom](/docs/features/research-evidence/debate-editor-zoom).

Upstream Debate Editor treats body zoom as transient: every editor opens at the
synced `defaultZoomPct` setting and forgets any zoom change on reload. On
debate-ai.com the last zoom the user picked is remembered and new editors open
at it.

- **Package:** `debate-editor`
- **Module:** `overlay/editor/remembered-zoom.ts` (ours, assembled into
  `src/editor/remembered-zoom.ts`)
- **Patched upstream files:** `src/editor/index.ts` (`setZoom`,
  `setLiveZoomPct`, the boot-time `liveZoomPct`) and
  `src/editor/multi-pane-shell.ts` (`zoomFocusedBy`, `zoomFocusedReset`, new
  pane records)
- **Storage:** `localStorage['debate-editor-zoom:<scope>']`, the zoom % as a
  string. `<scope>` is the signed-in email (lower-cased) read from the
  `debate-editor-account-sync` cache that `collab/account-sync.ts` keeps, or
  `guest` when signed out. It is read raw so the zoom module never starts that
  module's network refresh.
- **Test:** `packages/debate-editor/test/remembered-zoom.test.ts`

## Rules

- Every committed zoom is saved: the single-pane `setZoom` (buttons, keys,
  wheel/pinch gestures, Morph jog wheel, reset), the mobile `setLiveZoomPct`
  (slider, pinch), and the multi-pane per-pane `zoomFocusedBy` / reset.
- The single-pane editor boots at the remembered zoom; a new multi-pane pane
  record opens at it. Both fall back to `defaultZoomPct` when nothing is stored
  or the stored value isn't a positive number, and both clamp to
  `ZOOM_MIN_PCT`..`ZOOM_MAX_PCT`.
- Not part of the synced `pmd-settings` object on purpose: zoom is a
  per-screen choice.

## Known gaps

- Panes already open in multi-pane don't follow a zoom change made in another
  pane; only panes opened afterwards do.
- The account scope comes from the cached account-sync status, so the very
  first page load after signing in on a new browser can read the `guest` zoom
  until that cache is written.
- Changing `defaultZoomPct` in settings has no visible effect once a zoom is
  remembered; Reset (100%) or a new zoom is what changes it.
