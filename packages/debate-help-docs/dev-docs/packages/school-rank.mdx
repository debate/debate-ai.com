`@debate-ai/school-rank` · [source on GitHub](https://github.com/debate/debate-ai.com/tree/master/packages/school-rank)

The top U.S. colleges (U.S. News 2027 Best National Universities, ranks 1-100) and the top public and
private high schools (U.S. News 2026-2027 Best High Schools where sourced, plus the Niche 2027 public and
private lists that `debate-rankings` bundles), a Fuse.js fuzzy search that filters by level (college / high
school), type, state or wordmark, URL-param parsing for it, and each school's wordmark logo from
`debate-icons` (png URLs behind `@debate-ai/school-rank/wordmarks`, so the main entry stays image-free).
The package README has the top 10 per division, the wordmark coverage of each top 100, the trademark
disclaimer for the privacy policy and use cases.
