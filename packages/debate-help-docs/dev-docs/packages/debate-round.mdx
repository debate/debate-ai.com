# debate-round

FIAT — the live round workspace: the ag-Grid flow spreadsheet, column navigation and
split view, the round setup dialog (tournament, teams, judges, spectators, winner), speech
doc panels, export and history dialogs, and the flow/settings stores behind them.

```tsx
import { DebateFlowPage, useFlowStore } from "debate-round"
```

Composes `debate-timer` for speech timing and recording and `debate-editor` for speech
docs; the flow types themselves live in `src/types/flow.ts`.

## Package layout

Logic lives under `src/`, grouped by role; tests live under `test/`.

```

│   ├── controls/     # column navigator, quick actions, split-mode toolbar

└── test/             # Vitest suites for the flow and storage helpers
```

## Flow History: Saved to account

`dialogs/FlowHistoryDialog.tsx`'s **Saved to account** tab lists the signed-in user's
`saved_flows` and `saved_rounds` rows (`GET /api/flows`, `GET /api/rounds`). The pure
helpers in `state/savedSummaryFilter.ts` decide what it shows: `filterSavedSummaries`
(search), `sortSavedSummaries` with `SAVED_SUMMARY_SORT_OPTIONS` / `toSavedSummarySort`
(newest, oldest, name — natural, case-insensitive, ties by `clientId`) and
`savedSummaryCountLabel` (`"3"`, or `"2 of 5"` while searching). Remove asks with
`confirm()` before calling `DELETE`, and a failed delete sets the row's status to
`"remove-error"`, which shows a `role="alert"` line. Deleting a saved round never
deletes its saved flows (the route only touches `saved_rounds`). The sort choice lives
in component state only — it is not synced or remembered across page loads.

A failed **Load** sets the row's status to `"load-error"` (kept apart from `"error"`,
which the Rounds tab's save chips read for the same flow ids) and stores
`describeSavedLoadFailure(kind, failure)` in `cloudLoadErrors` / `cloudRoundLoadErrors`:
a `null` from `fetchSavedFlow` / `fetchSavedRound` (a 404 or 401) reads "no longer in
your account", a thrown `Error` shows its message (the route's 422 "damaged … you can
remove it" comes through as is), anything else a generic "try again". The line is a
`role="alert"` under the row and is cleared when the dialog reopens. Loading a saved
round fetches its missing flows with `.catch(() => null)`, so a flow that fails to load
is skipped like one that was never saved instead of failing the whole round.
