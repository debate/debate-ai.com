# Packages

One page per workspace package under `packages/`: what it exports, how the app consumes it
and how to work on it (from the package's README, or its entry in `packages/README.md`), then
its **dependency graph** and **file tree**, scanned from the source at build time.

The upstream git submodules (`debate-editor-cm`, `debate-tournaments-tabroom`,
`debate-rankings-sync-data`) are other projects' code and have no page here.
