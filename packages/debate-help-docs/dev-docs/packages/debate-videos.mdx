# debate-videos

LEARN — the video library: search and filtering, video grids and cards, the persistent
YouTube player (with picture-in-picture and a queue), and lecture and dictionary pages.
The rankings leaderboard and team profiles are in `debate-rankings-adapter`
(`@debate-ai/rankings-adapter/leaderboard`); the admin panels and the YouTube sync are in
`debate-videos-admin`.

```tsx
import {
  LecturesPage,
  PersistentVideoPlayer,
  CategoryDockProvider,
  useVideoPlayerStore,
} from "debate-videos"
```

Video data lives in the app's `videos` SQL table and is served a page at a time by
`/api/videos`; `src/data/` holds the row conversion and the filter/sort/facet query that
both the API and the in-browser index run.

## Package layout

Logic lives under `src/`, grouped by role; tests live under `test/`.

```
debate-videos/
├── src/
│   ├── components/   # cards, grids, search bar, player, stats modal
│   ├── context/      # category dock context
│   ├── data/         # video rows, the shared query, stacks, lecture/round-level classifiers
│   ├── hooks/        # paginated video feed, infinite scroll, watch history
│   ├── panels/       # lectures, dictionary, statistics and watch pages
│   ├── state/        # persistent video player store
│   ├── types/        # video and topic types
│   └── index.ts      # public entry point
└── test/             # Vitest suites
```
