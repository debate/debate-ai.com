# debate-videos

LEARN — the video library: search and filtering, video grids and cards, the persistent
YouTube player (with picture-in-picture and a queue), and lecture and dictionary pages.
The rankings leaderboard and team profiles are in `debate-rankings`
(`@debate-ai/rankings/leaderboard`); the admin panels and the YouTube sync are in
`debate-videos-admin`.

```tsx
import {
  LecturesPage,
  PersistentVideoPlayer,
  CategoryDockProvider,
  useVideoPlayerStore,
} from "debate-videos"
```

Video data lives in the app's `videos` SQL table and is served a page at a time by
`/api/videos`; `src/data/` holds the row conversion and the filter/sort/facet query that
both the API and the in-browser index run.

## Watch page preferences

The watch page's remembered choices — copy format, auto-scroll, skip breaks and the live
caption line — are one JSON object under `debate-videos:watch-preferences`, read and
written through `src/lib/watch-preferences.ts` (`readWatchPreference` /
`writeWatchPreference`). Signed in, the object syncs as the `videoWatchPreferences`
tool-record collection (`@debate-ai/research-evidence`'s
`account-sync/watch-preferences-codec.ts`): one `preferences` record, merged field by
field so a choice made on only one device is kept, with the account winning where both
chose. The older per-choice keys (`debate-videos:copy-format`, `…:watch-auto-scroll`,
`…:watch-skip-breaks`, `…:watch-live-caption`) are still read when the object has no
value for a choice, and each is removed the next time its choice is written. An open
watch page reads its choices on load, so a change from another device applies on the
next visit, not live.

## Flow chart

The watch page's graph-icon button (beside Edit, on any video with speeches) opens
`components/videos/watch/flow-chart/DebateFlowChartDialog.tsx`, lazy-loaded so neither the
modal nor D3 downloads until it is pressed. It first outlines the last four team speeches
(`MIN_SUMMARIZED_SPEECHES`, or every speech when the box is ticked) that have a transcript
but no LLM summary, through the same `requestSpeechSummary` call and shared
`video_ai_results` `summary` kind as the speech tabs. Then every outline goes to
`/api/reason-ai` (`free: true`: the user's own key first, then the shared `openrouter/free`
key through write-language) with the viewer's editable instructions and a fixed JSON reply
contract (`src/lib/debate-flow-chart.ts`). `parseFlowChartResponse` normalizes sides, drops
dangling parents and links, breaks parent cycles, caps the chart at 40 bubbles and salvages
the complete bubbles from a reply cut off by the token limit. `DebateFlowChartGraph.tsx`
draws it with `d3-force`, `d3-zoom` and `d3-drag`, imported inside an effect so they are
client-only: aff bubbles blue on the left, neg red on the right, sub-bubbles hung off their
argument, dashed links for answers, extensions and related arguments.

Every bubble carries a `speech` label (sub-bubbles inherit their parent's); `flowChartSpeechColumns`
orders the chart's speeches by the round, matching labels loosely, and gives each a shade
(`speechShade`: aff hues 200–240, neg 352–12). The graph has two layouts: **Speech columns**
(`columnPositions`, fixed, one column per speech, sub-bubbles under their argument) and **Free
arrange** (force layout with a radial force pulling the most-linked bubbles to the centre;
dragging is only enabled here). The speech buttons grey out unfocused speeches and switch to
columns. Summaries and the chart call retry up to 3 times (`withAiRetries` in
`speech-ai-client.ts`) on 408/425/429/5xx, network errors and unreadable replies, but not on
sign-in errors or the plan's daily limit (a 429 whose body has `limit`). A speech whose summary
still fails is sent as the first 8,000 characters of its captions instead of being left out.

Known gaps: the chart itself is kept only in this browser (localStorage
`debate-ai:flow-chart:<videoId>`), not shared like the outlines, because the prompt is
editable; the free plan's 2,048-token cap on the shared key can cut a long round's chart
short (the parser keeps what arrived).

## Package layout

Logic lives under `src/`, grouped by role; tests live under `test/`.

```
debate-videos/
├── src/
│   ├── components/   # cards, grids, search bar, player, stats modal
│   ├── context/      # category dock context
│   ├── data/         # video rows, the shared query, stacks, lecture/round-level classifiers
│   ├── hooks/        # paginated video feed, infinite scroll, watch history
│   ├── panels/       # lectures, dictionary, statistics and watch pages
│   ├── state/        # persistent video player store
│   ├── types/        # video and topic types
│   └── index.ts      # public entry point
└── test/             # Vitest suites
```
