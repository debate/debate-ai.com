# Debate AI Docs

This is the documentation site for [debate-ai.com](https://debate-ai.com), covering:

- **[Guides](/docs/guides)** — task-oriented walkthroughs of the app's tool groups: [training](/docs/guides/training-tools), [practice](/docs/guides/practice-tools), and [research collaboration](/docs/guides/research-collaboration). Every tool page in the app links back to its guide.
- **[Features](/docs/features)** — behavior specs for every feature in the product, sourced from `docs/features/` in the monorepo.
- **[Packages](/docs/packages)** — READMEs for every workspace package in `packages/`.

See the [root README](https://github.com/debate/debate-ai.com#readme) for a product overview of CARDS, FIAT, LEARN, STREAM, and REASON.
