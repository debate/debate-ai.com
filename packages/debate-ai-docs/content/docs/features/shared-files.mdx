# Shared Files (Topic Starters for everyone)

The admin-only "Topic Starter" evidence-pack library is now a shared-file
library any signed-in user can contribute to and manage: share a document
from the editor, upload a DOCX/ZIP, keep files private until they're ready,
and let anyone open a published file read-only or save an editable copy.

- **Route:** `/library?tab=shared`; files open at `/reason-editor?shared=<id>`
- **Nav:** the Reason Editor sidebar's "Shared Files" panel; the editor
  header's "Share to library" button
- **Package:** `debate-round` (`state/sharedFiles.ts`,
  `round/shared-files-client.ts`), `apps/debate-ai.com`
  (`/api/shared-files/**`, `lib/shared-files/import-docx.ts`)

## Access rules

- Published rows are public; unpublished rows are owner-only.
- Only the owner can rename, edit, retag, move, publish/unpublish, or
  delete. Admin packs (no owner) are read-only for users.
- Re-sharing the same document updates its existing shared copy.

## Data flow

```
GET    /api/shared-files?scope=public|mine|all
POST   /api/shared-files            share a document, or create from a payload
GET    /api/shared-files/:id        PUT (owner) / DELETE (owner, cascades folders)
POST   /api/shared-files/:id/copy   save a copy to my documents
POST   /api/shared-files/upload     DOCX/ZIP (≤25 files) → nested folder rows
```

## Known gaps

No per-user storage quota beyond the per-upload cap, no moderation path
for user-published files, free-text tags, and a shared copy doesn't follow
later edits to its source document.
